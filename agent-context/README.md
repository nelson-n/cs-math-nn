# agent-context

Running context and documentation for AI agents working in this repo. Human-readable too.

## Read order

1. `repo-overview.md`: what this repo is and where things live.
2. `conventions.md`: how files are written here. Match it when adding or editing content.
3. `session-log.md`: the most recent entries, to see what was last worked on.

## Maintenance rules

- **Append to `session-log.md`** at the end of any session that changes the repo. Put the newest entry at the top and include the date, what changed, and anything left unfinished.
- **Update `repo-overview.md` / `conventions.md`** only when the structure or conventions actually change.
- The root `README.md` is the public curriculum index and the source of truth for to-dos. Don't copy its to-do lists here; link to them.
- Keep these files short. Record facts that aren't obvious from the code or git history.
